# Voicelog AI: 상세 UX 기획 및 구현 가이드 본 문서는 Stitch에서 디자인된 고해상도 UI를 바탕으로, Claude Code 등을 통해 Flutter로 실제 구현할 때 참고해야 할 상세 UX 로직과 기술적 요구사항을 정의합니다. --- ## 1. 공통 디자인 원칙 (Global UX) - **폰트**: 'Pretendard' (Variable) 사용. 한국어 가독성에 최적화된 자간(-2%)과 행간(1.6~1.8) 적용. - **컬러 시스템**: - Primary: `#3182F6` (Vivid Blue) - 신뢰감과 전문성. - Emotion Colors: 기쁨(Yellow), 슬픔(Blue), 평온(Green), 화남(Red). - **인터랙션**: iOS의 탄성 스크롤과 Android의 햅틱 피드백을 적재적소에 배치하여 '고급스러운 도구' 느낌 강조. --- ## 2. 화면별 UX 상세 사양 ### [Screen 1] 홈 (캘린더 & 목록) - **핵심 목표**: 사용자가 본인의 기록 빈도를 한눈에 파악하고, AI의 주간 분석을 통해 기록의 가치를 느끼게 함. - **UX 포인트**: - **캘린더**: 기록이 있는 날은 파란색 점(Dot) 또는 강조 표시. 탭 시 해당 날짜의 일기 목록으로 스무스하게 스크롤. - **주간 요약 카드**: LLM이 분석한 최근 7일간의 감정 흐름을 한 문장으로 요약 제공 (예: "이번 주는 평온한 저녁이 많았네요."). - **최근 기록**: 카드 탭 시 '일기 상세'로 이동. 스와이프 시 '삭제' 메뉴 노출. ### [Screen 2] AI 녹음 및 처리 (핵심 화면) - **핵심 목표**: '내 목소리를 AI가 경청하고 분석하고 있다'는 시각적 피드백 제공. - **UX 포인트**: - **실시간 파형**: 오디오 입력 레벨에 따라 부드럽게 움직이는 Waveform 구현 (정적 이미지 아님). - **실시간 STT**: 인식된 텍스트가 카드 내에 실시간으로 타이핑되는 효과. - **AI 보정 (Qwen)**: 녹음 종료 후 'AI가 일기를 다듬는 중...'이라는 텍스트와 함께 Shimmer 애니메이션 노출. - **자동 태깅**: 보정 완료 시 추출된 감정과 키워드 태그가 팝업 형태로 부드럽게 등장. ### [Screen 3] 일기 상세 및 인사이트 - **핵심 목표**: 분석된 데이터(감정, 메타데이터)를 시각적으로 풍부하게 보여주어 자기 성찰을 도움. - **UX 포인트**: - **감정 분석 섹션**: 도넛 차트 또는 게이지 바를 통해 해당 일기의 지배적인 감정 수치 표시. - **AI 어드바이스**: LLM이 일기 내용을 바탕으로 건네는 짧은 위로 또는 질문 (예: "비 오는 날의 여유가 Alex님께 큰 힘이 된 것 같아요. 내일은 어떤 기분일까요?"). - **원문 대조**: 보정된 일기와 원본 STT 텍스트를 토글(Toggle) 버튼으로 비교 가능하게 구성. --- ## 3. 기술 구현 가이드 (Claude Code용) - **데이터 레이어**: SQLite 또는 Hive를 사용하여 로컬 DB 구축. 오디오 파일은 로컬 스토리지 저장. - **LLM 연동**: Local LLM(Qwen) API 엔드포인트와 통신하는 `VoiceLogProvider` 클래스 구현. - **상태 관리**: Provider 또는 Riverpod을 사용하여 녹음 중(Recording) -> 처리 중(Processing) -> 완료(Done) 상태를 명확히 분리. - **최적화**: 반응 속도 개선을 위해 오디오 처리와 LLM 요청은 Isolate 또는 비동기 백그라운드 작업으로 처리. --- ## 4. 향후 확장성 (Metadata 활용) - 추출된 메타데이터(장소, 시간, 감정)를 기반으로 '한 달간 가장 행복했던 장소', '우울할 때 듣기 좋은 내 목소리' 등의 개인화된 리포트 기능 추가 제안.
