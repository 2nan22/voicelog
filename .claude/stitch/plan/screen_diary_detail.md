## 각 요소 상세

### AppBar
- 좌측: 뒤로가기 화살표 아이콘
- 제목: 날짜 형식 `2026년 4월 11일` (titleLarge)
- 우측: 삭제 아이콘 버튼 (`delete_outline`, 24dp)

### 감정 칩 + 시간 (Row)
- 좌측: EmotionChip 컴포넌트 (design_system.md 참고)
- 우측: 시간 텍스트 `오후 3:45` (labelSmall, outline 색상)
- 아래 여백: 12dp

### 태그 칩들 (Wrap)
- 기본 Chip 컴포넌트
- 배경: secondaryContainer
- 텍스트: onSecondaryContainer, labelMedium
- 칩 간 간격: 8dp
- 형식: `#산책`
- 아래 여백: 0dp (Divider가 처리)

### 구분선
- Divider, 상하 여백 24dp
- 색상: outlineVariant

### 일기 본문 텍스트
- 스타일: bodyLarge
- 색상: onSurface
- 줄 간격: 1.8 (넓은 줄 간격으로 가독성 강조)
- 좌우 패딩: 없음 (화면 패딩 16dp로 처리)
- 아래 여백: 32dp

### 원문 보기 섹션

**접힌 상태 (기본):**
```
┌─────────────────────────────────┐
│  ∨  원문 보기                   │  ← TextButton.icon
└─────────────────────────────────┘
```

**펼친 상태:**
```
┌─────────────────────────────────┐
│  ∧  원문 숨기기                 │  ← TextButton.icon
│                                 │
│  오늘 친구 만났어 날씨 좋고      │  ← 원문 텍스트
│  커피 맛있었음 기분 좋았다       │
└─────────────────────────────────┘
```

- 버튼: TextButton.icon (`expand_more` / `expand_less` 아이콘)
- 원문 텍스트: bodyMedium, outline 색상 (보정본보다 연하게)
- 원문 배경: surfaceDim, borderRadius 8dp, 패딩 12dp

## 삭제 확인 다이얼로그

삭제 아이콘 탭 시 표시:
```
┌──────────────────────────┐
│  일기 삭제               │  ← title
│                          │
│  이 일기를 삭제하면      │  ← content
│  복구할 수 없어요.       │
│                          │
│  [취소]        [삭제]    │  ← 버튼 Row
└──────────────────────────┘
```

- AlertDialog (Material 3)
- `취소`: TextButton
- `삭제`: FilledButton (error 색상 배경)
