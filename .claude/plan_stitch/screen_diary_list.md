## 각 요소 상세

### AppBar (Large, Collapsing)
- 기본 상태: 큰 타이틀 `Voicelog AI` (displaySmall 크기)
- 스크롤 후: 일반 AppBar 높이로 축소, 타이틀은 titleLarge
- 우측 아이콘: 설정 아이콘 (`settings_outlined`, 24dp)
- 배경: surface 색상

### 날짜 그룹 헤더
- 텍스트: `오늘` / `어제` / `2026년 4월 10일` 형식
- 스타일: labelLarge, fontWeight bold
- 색상: primary (`#6B8CFF`)
- 패딩: 상 16dp / 좌우 16dp / 하 8dp

### 일기 카드 (DiaryCard)
```
┌────────────────────────────────────┐
│ ▌  오늘은 정말 좋은 하루였다.       오후 3:45 │
│    어제 친구를 만나서 커피를...              │
│    #산책   #친구   #날씨                    │
└────────────────────────────────────┘
```

- 외형: Card (elevation 2dp, borderRadius 12dp)
- 내부 패딩: 16dp 전체
- 좌측 감정 컬러 바: 너비 4dp, 높이 60dp, borderRadius 2dp
  - 기쁨: `#FFC107` (노랑)
  - 슬픔: `#42A5F5` (파랑)
  - 평온: `#66BB6A` (초록)
  - 화남: `#EF5350` (빨강)
- 컬러 바와 텍스트 영역 간격: 12dp
- 본문 텍스트: bodyMedium, 2줄 제한, 말줄임표(...)
- 태그: labelSmall, primary 색상, 최대 3개
- 시간: labelSmall, outline 색상, 우측 정렬

### FAB (Floating Action Button)
- 타입: Extended FAB (아이콘 + 텍스트)
- 아이콘: `mic` (흰색)
- 텍스트: `녹음`
- 배경: primary (`#6B8CFF`)
- 위치: 우하단, 하단 여백 24dp, 우측 여백 16dp

---

## 상태별 화면

### 로딩 중
- 날짜 헤더 자리: 회색 shimmer 바 (너비 60dp, 높이 16dp)
- 카드 자리: shimmer 플레이스홀더 5개 (각 높이 80dp, borderRadius 12dp)
- shimmer 색상: surfaceContainerHighest → surface

### 빈 목록
- 화면 중앙에 안내 문구
- 아이콘: `mic` (64dp, outline 색상)
- 텍스트: `아직 작성된 일기가 없어요` (bodyLarge, outline 색상)
- 하위 텍스트: `아래 버튼을 눌러 첫 일기를 기록해보세요` (bodyMedium, outline 색상)
- FAB는 그대로 표시

---

## 스크롤 동작

- 전체 화면 스크롤 가능 (CustomScrollView)
- AppBar는 스크롤에 따라 축소 (Large → 일반)
- FAB는 스크롤 중 숨겨졌다가 멈추면 다시 표시 (선택 사항)

## 다크 모드 고려사항

- 카드 배경: dark surface 자동값
- 감정 컬러 바: 동일 색상 유지
- AppBar: dark surface 자동값
