## 각 요소 상세

### AppBar
- 좌측: 뒤로가기 화살표 아이콘
- 제목: `오늘의 일기` (titleLarge)
- 우측: `저장` 텍스트 버튼 — **처리 완료 상태에서만 표시**

### STT 텍스트 영역
- 외형: 카드 또는 Container, borderRadius 12dp, surface 배경
- 크기: 화면 높이의 약 40~45%
- 패딩: 내부 16dp
- 내용 (상태별):
  - **대기**: `탭하여 녹음을 시작하세요` (bodyLarge, outline 색상, 중앙 정렬)
  - **녹음 중**: 인식 중인 텍스트 실시간 출력 (bodyLarge, onSurface, 좌측 상단 정렬)
  - **AI 처리 중**: shimmer 플레이스홀더 3줄 (높이 각 20dp, 간격 12dp)
  - **처리 완료**: 보정된 일기 텍스트 (bodyLarge, onSurface)

### AI 결과 영역 (처리 완료 시만 표시)
- STT 텍스트 영역 아래, 파형 위
- 감정 칩 + 태그 칩들이 가로 줄 흐름(wrap)으로 배치
- 감정 칩: EmotionChip 컴포넌트 (design_system.md 참고)
- 태그 칩: 기본 Chip, primary 색상 텍스트

### 음성 파형 (Waveform)
- 크기: 전체 너비 × 60dp 높이
- 구성: 30개의 세로 막대
  - 막대 너비: 약 6dp
  - 막대 간격: 약 5dp
  - 최소 높이: 4dp (정지 상태)
  - 최대 높이: 48dp (최대 진폭)
  - 모서리: 2dp (rounded)
  - 색상: primary (`#6B8CFF`)
- 상태별:
  - **대기/완료**: 모든 막대 4dp (평탄선)
  - **녹음 중**: 막대들이 서로 다른 높이로 파형 형성, 애니메이션

### 마이크 버튼 (핵심 컴포넌트)
```
   상태 1 - 대기:
   ┌──────────────────────────────────┐
   │          ○  ←── 버튼 (72dp 원형) │
   │        primary 배경 + 흰 🎙 아이콘│
   └──────────────────────────────────┘

   상태 2 - 녹음 중:
   ┌──────────────────────────────────┐
   │     ○        ← 외부 펄스 링       │
   │   ╔═══╗     ← 버튼 (error 색상)  │
   │   ║ ■ ║     ← 정지 아이콘        │
   │   ╚═══╝                          │
   └──────────────────────────────────┘

   상태 3 - AI 처리 중:
   ┌──────────────────────────────────┐
   │          ○  ← 버튼 (비활성, 회색) │
   │        CircularProgressIndicator │
   └──────────────────────────────────┘
```

**버튼 상세:**
- 크기: 72×72dp 원형
- 상태별 배경:
  - 대기: primary (`#6B8CFF`)
  - 녹음 중: errorContainer
  - 처리 중: surfaceContainerHighest (비활성)
- 상태별 아이콘:
  - 대기: `mic` (32dp, 흰색)
  - 녹음 중: `stop` (32dp, onErrorContainer 색상)
  - 처리 중: CircularProgressIndicator (24dp, primary 색상)

**펄스 링 (녹음 중에만):**
- 버튼과 동심원
- 크기: 버튼(72dp)보다 점점 커지다가 사라짐 (72dp → 100dp)
- 색상: primary 20% 투명도
- 애니메이션: 1초 주기 반복
